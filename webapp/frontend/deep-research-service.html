Reusable API surface

Expose deep research as a service, not only as a page.

Use this playground to send a JSON payload into the project's deep research core and inspect the returned output. The response can come back as a markdown report, structured JSON, or both.

Test the endpoint Agent discovery
One core, many consumers Other products can call one endpoint and choose the output mode they need.
Structured or open-ended Return a full research report, a strict JSON response, or both in the same run.
Grounded in sources Keep visited URLs, images, costs, and local-document usage visible in the response.
Endpoint

POST /api/deep-research-service

Receives a JSON payload and executes the research flow with optional structured formatting.

History

GET /api/deep-research-service/runs

Lists recent runs saved by the service so you can inspect requests and outputs later.
